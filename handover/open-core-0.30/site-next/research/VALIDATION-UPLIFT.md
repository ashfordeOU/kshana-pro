## The promotion rule, and the two policy questions

A row is VALIDATED only with an `ExternalDataset` oracle (the invariant tests in `src/verification.rs` enforce this). Across the 83 existing VALIDATED rows, three kinds of oracle have been accepted: (1) real measured data, (2) an independent third-party library computing a uniquely defined quantity (allantools, Orekit, ANISE, RTKLIB, pymcdm, lamberthub), (3) published reference vectors or tables. This report's **strict rule** accepts only those. Two further standards are applied inconsistently today:

- **P1: a published worked value computed from the same closed form the row implements.** Accepted for rows 68, 190, 191, 199 and 212; refused for the launch-geometry and lunar-time crossover rows (M018, M033) on the grounds that it is a transcription check. Rows affected: M058, M093, M101, M129.
- **P2: a third-party numerical library (numpy/LAPACK) recomputing a uniquely defined linear-algebra quantity on representative inputs.** Accepted for rows 96, 152, 157 and 165; refused for M041 and M085 with the same evidence. Rows affected: M025, M026 (and a licence problem: the only independent tool, gLAB, is CC BY-NC-ND), M041, M080, M085.

Recommendation: write the rule down once, in `docs/VALIDATION.md`, and apply it both ways. If P1 is refused, rows 68/190/191/199/212 deserve a second look. If P2 is accepted, M041 and M085 are free promotions.

Lockheed Martin's GPS IIR/IIR-M patterns are publicly released (https://www.navcen.uscg.gov/node/599), and the LuGRE flight data are on Zenodo under CC BY 4.0 (https://doi.org/10.5281/zenodo.16411686).

## Method

Every row was read from `src/verification.rs` (requirement, capability, module, tests and oracle text), with `docs/VALIDATION.md`, `docs/MODELLED-RATIONALE.md` and `docs/PROVENANCE.md` for the rules. The 83 VALIDATED oracles were listed to calibrate what the matrix accepts. The repository's `xval/`, `tests/fixtures/`, `scripts/fetch_*.sh` and the real-data cache were checked for material that makes a promotion cheap. Public oracles were confirmed on the web where the verdict depends on them (LuGRE, GPS IIR patterns, JammerTest, TEXBAT, MagNav, TU Delft densities, NeQuick G, gLAB licence, the 2nd EOP PCC, the Bulletin A accuracy formula, the BeiDou performance standard). An internal cross-check, a second in-house model, or agreement with Kshana's own earlier output was never counted as an oracle. Counts in this report were computed from the parsed matrix, not typed.
