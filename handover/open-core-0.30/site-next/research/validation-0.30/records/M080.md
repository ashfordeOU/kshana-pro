Oracle computation (by the libraries' own algorithms, not the module's inverse-variance shortcut):
- Full-set estimator: `S_ff = numpy.linalg.lstsq(W^1/2 G, W^1/2)` with `G = 1_N`,
  `W = diag(1/sigma_i^2)`. Fault-free sigma `= sqrt(S_ff Sigma S_ff^T)`, bias `= sum |S_ff,i| |b_i|`.
- Exclusion subset j: `S_j` from `lstsq` on the rows other than j, embedded back into N columns;
  `sigma_j = sqrt(S_j Sigma S_j^T)`; separation `Delta_j = S_j - S_ff` and its standard deviation
  `sigma_ss,j = sqrt(Delta_j Sigma Delta_j^T)` (the general formula, not the nested-estimator
  identity the module uses); bias `= sum |S_j,i| |b_i|`.
- Multipliers (inputs): `K_fa = scipy.stats.norm.isf(p_fa / (2N))` for N >= 2, `norm.isf(p_fa/2)`
  for N = 1; threshold `T_j = K_fa sigma_ss,j`.
- PL: `scipy.optimize.brentq` root of `sum_k p_k norm.sf((PL - b_k - T_k)/sigma_k) = ir/2` with the
  fault-free mode `p = 1 - sum p_j, T = 0`.
- Driving subset: `argmax_j (bias_j + T_j + sigma_j)`.

Inputs: 300 cases from a fixed seed (20260930), N uniform in 1..8, sigma_i log-uniform in
[0.5 ns, 100 ns], b_i uniform in [0, 20 ns], p_fault log-uniform in [1e-6, 1e-3], ir_budget
log-uniform in [1e-7, 1e-4], p_fa log-uniform in [1e-6, 1e-2]. Committed to the fixture.

Tolerance (fixed now, from the plan): **PL relative error <= 1e-9** (|kshana - numpy| <= 1e-9 |numpy|)
on every case; **driving subset index identical** on every case with N >= 2 (and None for N = 1).
