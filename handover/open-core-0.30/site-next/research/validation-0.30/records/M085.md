## Pre-registration (written 2026-10-01T03:22Z, before any comparison was run)

Oracle kind: **P2**. Oracle: numpy 2.3.5 (BSD-3-Clause, https://numpy.org) `linalg.cholesky`
(LAPACK potrf), `linalg.solve` (LAPACK gesv) and `linalg.inv`, from `~/Code/kshana-oracles/.venv`.

Why a new test file: the plan names the existing `tests/gls_reference.rs` with a 1e-12 bar, but that
test asserts an ABSOLUTE 1e-10 on one 3x3 case and does not compare the factor or the whitened
vector. The plan's 1e-12 bar is therefore enforced in a new test,
`tests/gls_whitening_numpy_oracle.rs::whitening_and_mahalanobis_match_numpy_lapack`, on a larger
committed input set; the existing test is left untouched.

Comparisons (Kshana `cholesky_lower`, `whiten`, `mahalanobis_sq` versus numpy):
1. Factor `L`: `cholesky_lower(Omega)` vs `numpy.linalg.cholesky(Omega)`.
2. Whitened residual `z = L^-1 r`: `whiten(Omega, r)` vs `numpy.linalg.solve(L_np, r)`.
3. Whitening operator `L^-1`: columns `whiten(Omega, e_i)` vs `numpy.linalg.inv(L_np)`.
4. Mahalanobis square: `mahalanobis_sq(Omega, r)` vs `r . numpy.linalg.solve(Omega, r)` (the
   identity z^T z = r^T Omega^-1 r, with the right side computed without any Cholesky).

Inputs: the existing 3x3 case from `tests/fixtures/gls/reference.json` plus 200 random SPD cases
from a fixed seed (20260930): N uniform in 2..8, `Omega = A A^T / N + diag(d)` with A entries
N(0,1) scaled by a per-case scale log-uniform in [1e-2, 1e2] and d uniform in [0.1, 1] times the
same scale squared, r entries N(0, scale). Condition numbers are written into the fixture.

Tolerance (fixed now, from the plan, 1e-12): for each matrix or vector, **infinity-norm of the
difference <= 1e-12 times the infinity-norm of the numpy value**; for the Mahalanobis scalar,
**|kshana - numpy| <= 1e-12 |numpy|**. Every case must pass.

Fixture: `tests/fixtures/gls_whitening_numpy_oracle/` (generator `gen_reference.py`,
`reference.json`, `NOTICE.md`).
