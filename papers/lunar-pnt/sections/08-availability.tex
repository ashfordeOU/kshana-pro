\section{Availability and reproducibility}

The engine is open source (\code{kshana}, AGPL-3.0-only, commercial licence
available) with each release archived on Zenodo \citep{baweja2026kshana}. The
analysis scripts, the committed aggregate data, and the seed lists reproduce
every figure from the public binary \citep{fernandezprades2018reproducibility}.
(ArXiv identifiers, the Zenodo DOI for the lunar release, and the repository URL
are inserted at posting.)
