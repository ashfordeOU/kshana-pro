# Pro sample assets

two page images. They are links to `../site-next/explorations/2026-09-27-combo/assets/pro/`, which

outputs of `kshana-pro mission build` (`docs/MISSION-DOSSIER.md`); regenerate them there, then copy
them into the site source. See `../SOURCES.md`.
