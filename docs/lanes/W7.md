## Done (code lives in `src/iq/campaign/`, `src/iq/cli/campaign.rs`, `src/python.rs`, `mcp/kshana-mcp/src/iq.rs`)

- **Test conditions** `kshana.test-conditions/1` (TOML/JSON, `conditions.rs`): metadata only.
  - Unit tests: `toml_and_json_parse_to_the_same_value_and_hash`, `receiver_notes_do_not_change_the_hash`,
    `errors_name_the_problem`, `overlapping_events_on_a_shared_satellite_are_refused`,
    `step_interpolation_holds_each_point`.
  - SigMF import (`events_from_sigmf = true`, `TestConditions::import_sigmf_events`), tested by
    `sigmf_annotations_import_as_the_same_events_as_a_written_table`.
- **Campaign file** `kshana.campaign/1` (`spec.rs`).
  - `data_class` (`synthetic` | `client-confidential`) is required and closed: `data_class_is_required_and_closed`.
  - Other unit tests: `wildcards_match_file_names`,
    `a_campaign_parses_with_defaults_and_refuses_unknown_keys`,
    `the_worker_count_does_not_change_the_run_hash`.
- **Runner** (`runner.rs`).
  - Content-hash cell keys, with a public `cell_key(&CellKeyInputs)`. Cells are written atomically;
    resume skips finished cells.
  - Parallel work items; each (recording, chain) group reads the recording once into one W1
    `TrackSession`.
  - `ScoreSink` is the `EpochSink`: `LOCKED` counts as locked, and a `false-lock` reason marks a
    false lock. `lock_source = "track-session"`.
  - `run.epochs` = csv | jsonl | binary writes W1's writers to `epochs/<key>.<ext>` plus
    `<key>.events.jsonl`. They are hashed into the cell.
- **Scorer** (`score.rs`), online and in bounded memory.
  - Metrics: availability, time to loss, J/S at loss, re-acquisition time (from offset and from loss),
    C/N0 degradation per stated-J/S bin, the MODELLED SSC reference using `jamming::q_factor` (the
    single source of Q, so W5's D5 flows through), false-lock episodes and rate, PLL/DLL jitter, and
    bars.
  - Time after a channel's last update counts as unlocked.
  - Unit tests: `loss_reacquisition_and_availability_follow_the_lock_timeline`,
    `degradation_bins_match_measured_and_modelled_values`,
    `false_lock_episodes_from_truth_and_from_the_tracker_flag`,
    `jitter_is_the_sample_std_of_locked_discriminators`,
    `time_after_the_last_update_counts_as_unlocked`.
- **Report** (`report.rs`): scorecard CSV/JSON, self-contained HTML (MODELLED labelled), DIGEST and a
  public `report::digest(out_dir)`. Bars apply at report time, with campaign bars overridden per
  recording by `[bars]`.
- **CLI**: `kshana iq campaign <toml> [--out --workers --no-resume --max-cells --dry-run --json]`,
  `iq campaign report <dir>` and `iq conditions <file>`.
- **Python**: `iq_test_conditions`, `iq_campaign` and `iq_campaign_report`, with stubs. Test:
