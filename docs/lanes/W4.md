## Mac probe (`.github/workflows/mac-probe.yml`, PR 18, 29ff483)
Manual (`workflow_dispatch`) run of one cargo command against a public `ashfordeOU/kshana` ref on the
self-hosted runner `[self-hosted, macos, arm64, kshana-pro]`.
- Inputs: `ref` (sha or branch, `[A-Za-z0-9._/-]`), `command` (default `cargo test --all --locked`; must
  start with `cargo `, no shell metacharacters; run as an argument list, never through a shell).
- Public no-token shallow fetch of `ref`; toolchain from its `rust-toolchain.toml`;
  `CARGO_INCREMENTAL=0`, `CARGO_PROFILE_DEV_DEBUG=0`; own `CARGO_TARGET_DIR` under `$RUNNER_TEMP`;
  log artifact `mac-probe-log-<run_id>` (7 days) plus the last 200 lines in the job output; cleanup
  always. Concurrency group `mac-probe` (one at a time, never cancelled, separate from CI; with one
  runner it still queues behind a CI job).
- Dispatch: Actions → Mac probe → Run workflow (or the GitHub API `actions_run_trigger` with
  `workflow_id: mac-probe.yml`, `ref: main`, inputs above).
  - W6 pin (lunar_frame_campaign scenario 2): `cargo test --test lunar_frame_campaign -- --nocapture`
  - Public issue #36 (macOS-local oracle failures): `cargo test --all --locked --no-fail-fast`
- **Not yet run end to end**: the first dispatch is its test. If the shallow fetch of a bare sha fails,
  pass the branch that contains it.
