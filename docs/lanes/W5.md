## D8, D9, D10 (0.34; tests in `tests/iq_signal_matrix.rs` land via W2; un-ignore the matching one)

Measured by W3 at 45 dB-Hz, one satellite, no data.

- **D8, acquisition step vs FLL pull-in.** The default step 2/(3T) leaves a residual up to
  1/(3T), but the default atan2 FLL pulls in only ±1/(4T). Galileo E1-B/E1-C (T = 4 ms,
  residual +83.3 Hz) false-lock at **+125.02 Hz**. PLI 0.97 is blind to it; E1-C secondary
  agreement is 54 %. On-grid, both lock. Fix: step ≤ 1/(2T), or a fine-Doppler refinement before
  hand-off. Check the 1 ms codes too. Touches the acquisition → track hand-off, so coordinate
  with W1.
- **D9, GPS L2C CM (T = 20 ms) can't hold lock**, even from a perfect start (PLI −0.08, M2M4
  15.8). The defaults (15 Hz PLL / 10 Hz FLL at T = 20 ms) give Bn·T = 0.3 / 0.2. Fix: scale the
  default bandwidths by integration time (Bn·T ≤ ~0.05–0.1), or per-signal defaults.
- **D10, BeiDou B1C only** (narrowed in matrix v2): C/N0 low at 5 MS/s (NWPR −2.45 dB, M2M4
  −1.32 dB). E1-B at the same rate is within 1 dB, BPSK within 0.4. The cause is not
  established (scene vs replica sampling of QMBOC/BOC parts). Investigate before fixing.

## GLONASS satellite id

- **0.33 (C), done in #50 (doc-only):** CHANGELOG and `docs/design/iq-notes/signals.md` state
  that a scene uses the frequency channel `k` as the `u32` satellite id, so `k = −7` is written
  as 4294967289 (`k + 2^32`); an `i32` cast recovers it. Python and MCP readers see the same.
- **0.34 (D), the coordinator's preference, plan needed before code:** identify GLONASS
  satellites by orbital **slot** (1–24, so `u32` stays) and add `freq_channel: i8` to
  `SceneSatellite` and `TruthRecord` plus a truth CSV column (`truth_from_csv` must accept files
  without it). CLI and Python take `--prn` as the slot, with a slot → k table (the ICD's
  default assignment, `k` shared by antipodal slots) overridable per satellite (e.g.
  `--glonass-k slot:k,…`). `SceneChannel::snapshot(sat_id: u32, …)` is unchanged, so this is
  additive. Other touch points: `build_code("glonass-l1of", id)` (now `k`) needs the slot → k
  lookup at the CLI/Python layer; acquire/track `--prn` for GLONASS should take the slot too,
  with a migration note, or keep `k` with a clear error. Size S–M. Write the plan and send it to
  the coordinator first.
