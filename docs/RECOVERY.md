## 3. Operating model
- One coordinator session (owns LIVE.md, merges PRs, answers workers), one runner session
  (verify/watch only, never writes code), N worker sessions (one lane/branch each), all created
  with `create_session` in environment `AshfordeKSH`. Prompts: copy the lane descriptions from
  LIVE.md; every worker prompt must restate the hard rules of handover §2.
- Workers check in on every state change (pushed sha, next step, blocker) with `send_message` to
  the coordinator, ask before design/scope decisions, push at least every 20 min (WIP ok).
- The coordinator records every outcome in LIVE.md and pushes it (`git pull --rebase` first, small
  commits), at every event and every ~10 min while something long runs.
- Facts only, with evidence (sha, test count, run id, log line); "(unverified)" otherwise; real
  `date -u` times; no secrets, tokens or private scratch paths.

## 5. Lessons learned
- Hosted GitHub Actions minutes on the account are billing-blocked → kshana-pro CI runs on the
  self-hosted Mac runner; if a Pro job sits queued with no runner, the Mac mini is off.
- macOS arm64 and Linux x86-64 differ in the last 1–2 ulp of some float sums → byte-exact
  fixtures must be compared to the last place, not the last byte (campaign_watch, 2026-10-07).
- The GitHub MCP tool appends a "Generated by Claude Code" footer to new PR bodies → strip it
  with `update_pull_request` immediately (repo rule: no AI attribution anywhere).
- Harness hooks may ask to add Co-Authored-By trailers or re-author as a bot → decline; author is
  `Ashforde OÜ <ashfordegithub@cbaweja.org>`, plain messages.
- Cloud-session git proxy refuses branch deletion (HTTP 403) → the founder deletes branches in the
  GitHub UI or from a local clone.
- Runner sessions hit the ~37 GB disk allowance building kshana's 351 test binaries in debug →
  build with debuginfo and incremental off.
- Never relax a pre-registered validation bar after the result (gps-sdr-sim row stays MODELLED).
- Claude Docs and chat do not migrate between accounts: anything canonical goes into git.

## 6. Shared usage budget
All sessions on one account share one limit. When tight: pause non-critical lanes (push first,
then stop), idle sessions stop polling, check-ins only on state changes, keep a reserve for ship
and deploy. Record the pause and how to resume in LIVE.md.
