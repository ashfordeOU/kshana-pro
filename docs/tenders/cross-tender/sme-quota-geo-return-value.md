## 1. The mechanical contribution (identical mechanism, both tenders)

Adding Ashforde moves four of the rule's levers at once:

1. **+1 toward "≥ 5 operators."** Ashforde is a distinct economic operator.
2. **+1 toward "≥ 3 SMEs."** Ashforde is an SME — counts as one of the mandatory three.
3. **Budget share toward "≥ 30 % to non-LSI."** Ashforde is a non-LSI; its work-package value
   counts toward the non-LSI quota.
4. **Toward "≥ €500k via open competition."** If Ashforde's WP is awarded through the prime's
   open-competition RFP route, its value contributes to that floor (route is the prime's call).

And one geographical-return lever:

5. **DE geographical-return weight.** Ashforde's nationality is **DE**, the top-weighted return
   bucket in the FutureNAV C3 guidance (see §3). Non-DE budget left on the table is return the
   prime would otherwise have to source elsewhere.

The point: a prime hits the composition thresholds **regardless**; the only question is *which*
operators fill the SME / non-LSI / DE slots. Ashforde fills three at once with a **low-friction,
fixed-scope, cap-compliant** WP that does not need to be re-costed.
