# Partner / prime target rubric (weighted scoring) — shelf asset

**PRIVATE — Ashforde OÜ internal working document.** A per-role **scoring rubric** that turns the C07
selection criteria into a weighted score, so when the search goes live a candidate can be ranked
objectively. **A shelf asset**: the candidate table is **blank by design** — no names until the
founder unparks the search.

## 1. The weighted rubric (score each candidate 0–5 per dimension)

Score each prospective prime/partner **0–5** on each dimension; multiply by the weight; sum to a
weighted total out of 100. Higher = better fit.

| # | Dimension | Weight | What a 5 looks like | What a 0–1 looks like |
|---|---|---:|---|---|
| 1 | **Nationality fit (DE > CH)** | **20** | DE-led / DE-heavy; compounds Ashforde's DE-SME geo-return | Heavy non-DE/non-CH with no geo-return offset |
| 2 | **ESA FutureNAV / NAVISP heritage** | **20** | Multiple FutureNAV/NAVISP/nav/quantum-PNT contracts; clear GATEKEEPER/ISRR track record | No relevant ESA programmatic heritage |
| 3 | **Complementarity (fills a role Kshana does NOT cover)** | **25** | Owns HW / RF payload / bus / SE / ground-AI; **no overlap** with the nav-performance WP | Already owns a strong nav-performance/trade capability (overlaps role 6) |
| 4 | **Facilities** | **10** | Labs / cleanrooms / benches / test ranges fit for the tender's hardware core | No relevant facilities |
| 5 | **SME-sub appetite (this cycle)** | **15** | Willing + able to add an SME sub via LoI/teaming within the ~3-week window | No appetite or no bandwidth in the teaming window |
| 6 | **Key-Person ownership (tender-specific)** | **10** | Can supply the mandatory Key Person (13503: quantum-nav; 13494: space-segment) — never Ashforde | Cannot supply it and no other member can |
| | **Total** | **100** | | |

**Decision bands (guidance):**
- **≥ 75** — strong fit; prioritise (on go).
- **55–74** — viable; pursue if higher-ranked targets do not engage.
- **< 55** — weak fit; do not pursue (likely a negative-signal partner — see C07 §4).

**Hard gates (a 0 here disqualifies regardless of total):**
- **Complementarity (dim 3) = 0** — overlaps the navigation-performance WP (no seat for Ashforde).
- Pressure for Ashforde to act as **prime / a Key Person / to bid hardware it does not own**.
- **Key-Person (dim 6)** cannot be satisfied by **any** consortium member (compliance fail).

## 3. How to use this (on go — founder-gated)

1. Unpark the search (founder go).
2. For each candidate, score dims 1–6 (0–5), apply weights, compute the weighted total.
3. Apply the hard gates (a disqualifying 0 overrides the total).
4. Rank by total within the decision bands; prioritise ≥ 75.
5. Only then proceed to C07's outreach kit (also founder-gated).
