# Kshana 0.38 + 0.39 release video

A neutral referee for GNSS receivers: Jammertest scoring first, then what else 0.38 and 0.39 added. Same format as the 0.36 + 0.37 set in `docs/handover-0.37/video/`: a 1920×1080 promo (82 s, 30 fps, h264), the same with the brand strip, a 1080×1080 showcase, and a poster for each.

Every number on screen is read from `src/data/numbers.json`, which is built from real engine runs; `NUMBERS.md` lists each command, the commit it ran at and what it printed. Logs written for the video are synthetic and say so on screen. The engine is the 0.39.0 build of kshana `integ/0.39.0` (commit `fc21ac45`).

## Rebuild

1. Build the engine: a kshana checkout at the commit in `NUMBERS.md`, `cargo build --release --bin kshana`.
2. Fetch the published Jammertest catalogue and plan (SHA-256 checked, outside the repository): `sh <kshana>/xval/jammertest-plan/fetch.sh <dir>`.
3. Run the commands: `python3 src/collect.py --engine <kshana> --bin <kshana>/target/release/kshana --plan <dir> --out src/data/raw` (needs `pip install fonttools`, which the engine's figure generator imports for its synthetic-log writers).
4. `python3 src/build_numbers.py` writes `src/data/numbers.json` and `NUMBERS.md`.
5. Render: `node src/render.mjs --variant promo --out kshana-0.38-0.39-promo-1920x1080.mp4` (also `branded`, `showcase`); `--still <seconds>` writes one frame, `--check 1` tests that every scene fits its box. Needs Playwright with Chromium and ffmpeg. `src/index.html`, `style.css` and `video.mjs` are the scenes: a pure function of the time, so the output is deterministic.

`src/data/raw/` is not committed (about 1.6 MB, regenerated by step 3). The fonts (Geist, Geist Mono, Unbounded; SIL Open Font License) and the mark are copies of the site's own.

## What is on screen

Advisory line on every frame; "synthetic log" wherever a log is synthetic; MODELLED wherever a figure is; the bars that were not met are shown as not met; the ledger as 388 rows, 176 VALIDATED. No agency branding, and no claim of endorsement by the test organisers.
