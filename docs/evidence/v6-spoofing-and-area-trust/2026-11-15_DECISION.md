# V6: E5 v3 spoofing benchmark and B5 v4 area trust: decision record (15 November 2026)

Written on **2026-11-15 (12:20 UTC)**. Roadmap 0.42 V6: "E5 v3 spoofing benchmark and B5 v4 area
trust, only where a new method is written down first. Misses stay published." The open engine's
published rows are unchanged and stay published: B4a E5 v2 NOT MET (AUC 0.6941), E5-PD MET (AUC
0.7410), B5 v3 NOT MET (T2).

## E5 v3 (B-iq spoofing on TEXBAT): no scored row in 0.42 from this work

* **Why not now.** All ten TEXBAT recordings have been scored and their per-recording AUCs are
  published (E5 v2 and E5-PD). Any new method designed now would be designed after seeing which
  attacks each statistic separates (ds1, ds3 and ds6 overlap). A score on the same ten recordings
  would not be blind, so it could not support a claim. New per-window statistics would also need
  the recordings, which stay on the owner's computer and are never redistributed.
* **The method written down now, for a future blind data set.** `E5 v3` (to be signed by the owner
  before any data): per recording, the E5-PD window score passed through a one-sided CUSUM with
  reference `k = 0.5` and decision `h = 5` in units of the score's median absolute deviation over
  windows 0 to 59 (the E5-PD baseline windows), the window score being the CUSUM statistic; same
  units, onset exclusion, minimum-data rule and AUC bar (≥ 0.70) as E5 v2. It is to be scored only
  on a spoofing data set that no Kshana code has read (candidates: a JammerTest 2027 recording
  under its licence, or a public set not yet fetched), with the scorer and an independent oracle
  committed before the first data file, as `xval/bench-e/README.md` asks.
* **Status:** NOT SCORED. Nothing is claimed.

## B5 v4 (area trust): no new method registered

* **What missed.** B5 v3 T2: 4 of 127 single-satellite faults not flagged (weak geometry: without
  the faulty satellite one or two stations still exceed `H_s`), and 2 of 67 two-satellite epochs
  flagged with one satellite (one of the two errors small).
* **Why no v4 now.** T2 counts a fault as detected when the injected satellite is flagged **and**
  every alarmed station is cleared. The four geometry misses are stations whose fix without the
  faulty satellite is still worse than `H_s`; no screen can clear them without changing what T2
  measures, which would loosen the bar. The two-satellite cases could be reduced by a residual
  consistency test after the screen, but that alone cannot meet T2's 100 % either. No method that
  can meet T2 as registered has been written, so none is registered.
* **Status:** NOT REGISTERED. B5 v3 stays published as NOT MET. A v4 is opened only when a method
  is written down that addresses the geometry misses within T2's definition.
