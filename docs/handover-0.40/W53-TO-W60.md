## Gotchas

- Commit as `git -c user.name="Ashforde OÜ" -c user.email="ashfordegithub@cbaweja.org" commit`, no trailers; the container default is "Claude". No PRs, no GitHub comments, no force-push or history rewrite.
- Push targets: kshana-pro `site/studio-0.38` and `site/i18n-0.40`; kshana `feat/studio-replay-0.38` and `docs/screenshots-0.40`. Anything else, ask the coordinator first.
- The auto-mode classifier blocks edits that weaken a check (check.py rule 17 had one; the owner approved one allowance, now the only one: CAPABILITY.md's dated 0.38.0 revision line). If a command is denied, retry once as a plain command, then report.
- build.py refuses recordings not stamped with the engine checkout's HEAD; the recorders must run at the checkout you build against, and the Cs5071A record (`realdata-cache`) must be reachable or the holdover figures come out blank.
- `build.py` and `check.py` run for about 2 minutes; run them in the background (the tool timeout is 120 s) and wait for the process, not for a marker in a log file (a stale marker misled me once).
- arXiv answers 429 now and then: retry `gen_publications.py`, or use `--offline`.
- The site check's rule 17 (engine version) fails on any docs statement of an older version; the engine's docs must be restated, not allow-listed.
- The preview-host limits (255 files, 64 MB, 15 MB a file) are not gating; kshana.dev deploys on Pages.
