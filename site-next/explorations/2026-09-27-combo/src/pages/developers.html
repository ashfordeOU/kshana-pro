Rust, Python, JavaScriptRun against v{{VER}}

Each program runs the bundled clock-holdover scenario (write it with kshana example clock-holdover > clock-holdover.toml) and prints the same one-line summary. The package READMEs carry the full versions.

src/main.rs · after cargo add kshana
use kshana::api;

fn main() -> Result<(), Box<dyn std::error::Error>> {
    let toml = std::fs::read_to_string("clock-holdover.toml")?;
    let out = api::run_toml(&toml)?;              // RunOutput { json, svg, summary, csv }
    println!("{}", out.summary);                  // the one-line result string
    std::fs::write("clock-holdover.result.json", &out.json)?;
    Ok(())
}

kshana::api also has run_scenario, validate_scenario, list_scenario_kinds and the orbit exporters. Rust docs

run.py · after pip install kshana
import json, kshana

toml = open("clock-holdover.toml").read()
result = json.loads(kshana.run(toml))        # the full result document
print(result["quantum"]["fom"]["integrity"])

result_json, chart_svg, summary = kshana.run_full(toml)
print(kshana.version(), summary)

The package also has validate_toml and list_kinds. Python docs

run.mjs · Node.js, after npm install kshana
import { readFileSync } from "node:fs";
import { createRequire } from "node:module";
import { initSync, run, summary, version } from "kshana";

const wasm = createRequire(import.meta.url).resolve("kshana/kshana_bg.wasm");
initSync({ module: readFileSync(wasm) });     // in a browser: await init()

const toml = readFileSync("clock-holdover.toml", "utf8");
const result = JSON.parse(run(toml));         // the full result document
console.log(version(), result.classical.fom.timing_p95_ns);
console.log(summary(toml));                   // the one-line result string
