## How editions are decided

- **Free core.** Every engine feature: every kind, scenario, command, MCP tool, binding, export, clock, band and body. The public source is `web/index.html`, the open-core card ("free under the AGPL-3.0 (or a commercial licence for closed/proprietary use), no feature gate"), backed by `README.md`, "The open engine is complete and usable on its own."
- **Pro.** Only four things, each quoted from a public file:
  - calibrated clock digital twins (`web/index.html`)
  - architecture trade studies ranked on a figure of merit (`web/index.html`)
  - audit-grade, reproducible evidence packs (`web/index.html`)
  - model-based systems-engineering and programme tooling (`README.md`, Support & professional services)
- **Custom study.** Five offers, each quoted from a public file:
  - a Modelled resilience study such as an optimism-gap audit (`web/index.html`, the study call to action)
  - custom sensor models calibrated to your hardware (`README.md`)
  - export-controlled resilience work under clearance and NDA (`web/index.html`, the "Custom & export-sensitive" card)
  - commercial support and integration (`README.md`)
  - training and consulting (`README.md`)
- **The commercial licence is not Pro.** Both public sources tie it to the open core: it is the same code under different terms (`web/index.html` open-core card; `LICENSING.md`). The register lists it next to Pro because buyers look for it there, but marks it Free core.

## What the check does, so the per-page work can rely on it

- **Enumeration.** `gen_features.py` enumerates from the repository, and each row's `source` names the file and line or the command it came from:
  - kinds: `kshana kinds --json`, cross-checked against `src/api.rs`
  - scenarios: `scenarios/*.toml`, with the kind from `kshana --validate`
  - command-line options: `src/main.rs`
  - MCP tools: `mcp/kshana-mcp/src/server.rs`
  - bindings: `Cargo.toml`, `pyproject.toml`, `kshana.pyi`, `src/wasm.rs`, `src/api.rs`, the plugin XML and `server.json`
  - exports: `src/main.rs`, `interchange.rs`, `ccsds_tdm.rs`
  - clocks: `clock_state.rs`, `telecom_timing.rs`, `clock_specs.rs` and scenario clock models
  - bands: an anchor regex per band in the source
  - bodies: `body.rs`
  - validation: `web/data/verification-matrix.json`, which is generated from `src/verification.rs`
  - Pro and Custom study: an exact public quote each
- **Placement.** Every placement comes from `placements.toml`. A feature without an entry is UNPLACED, never defaulted. An entry for a feature that no longer exists is a BAD_PLACEMENT.
- **Whole identifiers only.** `clock` never matches `clock-holdover`, `spoof` never matches `spoof-detect`, and `lunar-vlbi-fim` never shows `lunar-vlbi`.
- **Ordinary words.** An identifier that is also an English word counts only when it is set as code, is an exact label or table cell, or is the text of the link that opens that scenario. A mention only inside a tooltip, search index or link target is NOT_SHOWN.
- **Truncated names.** A ledger requirement cut off with "…" counts only if its visible prefix is unique.
- **Edition on the page.** The check reads the site's own edition containers (`#pro`, `#pro-band`, `.pro`, `.ed-pro`, `.tier.pro`, and cards headed Open core, Pro or Custom) and the "Pro:", "Custom:" and "Commercial licence:" labels. It flags any claim whose public source gives it a different edition.
- **Unregistered names.** It flags as UNREGISTERED:
  - a scenario linked with `?scenario=`
  - a `*.toml` file name
  - a top-level `kind = "..."`
  - a `kshana` command-line option
  - a snake_case name in the MCP section that is not an MCP tool
  - a code identifier that appears nowhere in the engine repository
- **Mutation-tested (13 of 13 pass).** The mutations:
  - removing one placement goes red; this was done both in a scratch copy and on the real `placements.toml`, which was then restored with the same checksum
  - fake kind, scenario, code identifier and MCP tool injected into scratch page copies
  - a deleted atlas node
  - substring overcount (`lunar-vlbi-fim` and `lunar-vlbi-x`)
  - prose `clock` against `kind = "clock"`
  - a Free feature labelled "Pro:"
  - a broken public quote
  - a wrong count
